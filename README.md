# 滑鼠錄製小工具

Windows Portable 免安裝版：多組滑鼠錄製、組合編排、重播與自動週期執行，內建一鍵更新。v1.1.0 起改用 F6／F7／F11 快捷鍵，避免原本 F9／F10 被其他程式占用。

## 下載與啟動

1. 前往 [最新版本下載頁](https://github.com/hungshin60229/mouse-recorder-releases/releases/latest)。
2. 下載 **MouseRecorder-windows-x64.zip**（請選 Release 附件，不是 Source code）。
3. 完整解壓縮到可寫入的資料夾，雙擊 **MouseRecorder.exe**。

適用 Windows 10／11 64 位元，不需安裝 Python，沒有命令提示字元視窗。

## 使用方式

| 操作 | 快捷鍵／按鈕 |
| --- | --- |
| 開始／結束錄製 | F6，開始前倒數 3 秒 |
| 重播 | F7，開始前倒數 3 秒 |
| 隨時停止 | F11（錄製、重播、週期等待皆有效） |
| 儲存／開啟錄製 | 工具介面按鈕，JSON 格式 |
| 調整重播 | 0.25～3 倍速、1～999 次 |
| 自動週期 | 設定間隔與秒／分鐘／小時，按「啟動週期」 |

支援移動、點擊、拖曳、左／右／中／側鍵與滾輪，不錄製鍵盤。

週期首次等待指定間隔後執行，每輪重播完成後再等待相同間隔；各輪不會重疊。工具需保持開啟。例：間隔 60 秒，每輪耗時 10 秒，兩輪開始時間相隔約 70 秒。

錄製以桌面的絕對座標重播，請保持相同視窗位置與螢幕配置。重播時手動使用滑鼠會互相干擾，請先按 F11 停止。建議用快捷鍵結束錄製，避免錄到點擊工具介面的操作。

每次新錄製會新增一組，原本的錄製仍會保留。錄製庫與組合自動儲存到工具旁的 `workspace.json`；重開工具會恢復資料，不會自動開始操作。若自動儲存失敗會顯示提示，請匯出錄製庫保存。

## 多組錄製與組合編排

1. 在「錄製庫與單組重播」錄製多組操作，選中錄製可改名或單獨重播；「開啟錄製」可把舊版 JSON 加入庫中。
2. 在「組合編排」按「新增組合」，選擇錄製組並設定等待時間、速度及次數，按「加入步驟」。同一組可以重複加入。
3. 用「上移／下移」調整順序。選中步驟後修改欄位，再按「套用修改」。
4. 按「執行組合」倒數 3 秒後依序執行。例如 **A → 等 10 秒 → B → 等 60 秒 → C**。
5. 勾選「循環整個組合」會持續循環；最後一步的等待用於下一輪，不循環時最後一步完成即結束。按 **F11** 隨時停止。

每一步的等待是該步重播完成後開始計時，支援 0 秒～24 小時；不會重疊執行。可建立多個組合並切換。使用「匯出整個錄製庫／匯入錄製庫」搬移全部錄製與組合；匯入會取代目前庫。分享錄製庫時請確認內容是你要分享的。

## 一鍵更新

停止操作後按工具內 **「一鍵更新」**。工具會檢查此儲存庫的最新正式 Release；有新版本時自動下載、驗證 SHA-256、替換執行檔並重新啟動。目前是最新版時顯示提示，不會重新下載。

更新前的錄製庫與組合會保存在本機 `recordings/_update_resume.json`，重新啟動後恢復。已儲存的 JSON 檔不會刪除，舊版執行檔保留為 `MouseRecorder.exe.bak`。週期與組合不會在重啟後自動執行。v1.0.0 的單組錄製也可在更新後恢復並加入錄製庫。

更新需網路及工具資料夾寫入權限，不需 GitHub 帳號。F11 可取消下載；若網路無回應，可能需等待連線逾時。下載或驗證失敗時保留目前版本。

錄製內容留在本機。更新功能只連線 GitHub 取得版本資訊及下載包。

## 發布附件

每個正式版本提供 `MouseRecorder-windows-x64.zip` 與同名 `.sha256` 驗證檔。此儲存庫用於提供下載與更新。
